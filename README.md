# Rent & Reuse

A campus-based platform that helps students rent, borrow, and share items with other students.

## Problem

Students often need certain items only for a short period of time. Buying these items can be unnecessary and expensive, while many other students already have items that they are not using.

## Solution

Rent & Reuse connects students who need an item with students who already have it. Students can browse available items, rent or borrow them, and manage their listings.

## Features

- Student login and signup
- Browse available items
- Search items
- Rent or borrow items
- Post items for others
- Item availability status
- Listing expiry
- Save items
- Student profiles
- Requests for items
- Ratings and trust features
- Light and dark mode
- Category-based browsing

## Technology Stack

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- Supabase Authentication

## Backend

Supabase is used for:

- Authentication
- Database
- Student profiles
- Items
- Requests
- Saved items
- Ratings

## How It Works

1. Student signs up or logs in.
2. Student searches for an item.
3. Student chooses Rent or Borrow.
4. Student sends a request.
5. The owner accepts the request.
6. Students connect and arrange the exchange.
7. The item is returned after use.

## Purpose

Rent & Reuse promotes affordable, convenient, and sustainable sharing within the student community.
